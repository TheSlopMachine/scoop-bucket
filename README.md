# TheSlopMachine's Scoop bucket

Automatically updated [Scoop](https://scoop.sh) bucket.

## Usage

```powershell
scoop bucket add slop https://github.com/TheSlopMachine/scoop-bucket
scoop install <app>
```

## Apps

| App | Description | Upstream |
|---|---|---|
| `clank` | Minimal CLI AI agent for the terminal (any OpenAI-compatible API) | [duckyouryan/clank](https://github.com/duckyouryan/clank) |
| `contextmenueditor` | Native Windows tool for editing Explorer's right-click menu entries | [TheSlopMachine/ContextMenuEditor](https://github.com/TheSlopMachine/ContextMenuEditor) |
| `fileassocmanager` | Native Windows tool to batch-set default apps for ~440 file formats (Windows 10/11) | [TheSlopMachine/FileAssocManager](https://github.com/TheSlopMachine/FileAssocManager) |
| `imageviewer` | Simple, cross-platform Qt image viewer inspired by GPicView | [AlienCowEatCake/ImageViewer](https://github.com/AlienCowEatCake/ImageViewer) |
| `llm-router` | Zero-bloat, self-contained OpenAI-compatible LLM routing gateway | [TheSlopMachine/llm-router](https://github.com/TheSlopMachine/llm-router) |
| `pineconemc` | Prism Launcher fork with Ely.by support | [ElyPrismLauncher/Launcher](https://github.com/ElyPrismLauncher/Launcher) |
| `workshopdl` | Standalone Steam Workshop downloader GUI (1000+ games, collections) | [imwaitingnow/WorkshopDL](https://github.com/imwaitingnow/WorkshopDL) |

Apps update automatically when their upstream projects publish new releases.
